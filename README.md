# CODSOFT Data Analytics Internship - Task 3: Data Visualization Dashboard

## 📌 Project Overview
This repository contains the solution for **Task 3: Data Visualization Dashboard** as part of the **CodSoft Data Analytics Internship**. The goal of this task is to create clear, customized visual plots (bar charts, line charts, pie charts, histograms, scatter plots) and design an interactive Power BI dashboard to present actionable insights from the cleaned Titanic dataset.

## 🛠️ Tools & Technologies
* **Programming & Libraries:** Python, Pandas, Matplotlib, Seaborn
* **Business Intelligence:** Power BI (DAX, Interactive Slicers, KPI Cards)
* **Environment:** VS Code / Jupyter Notebook / Power BI Desktop

## 🔑 Key Features & Visualizations
1. **Python Data Visualizations:**
   * **Bar Charts:** Survival rate analysis across passenger classes (`Pclass`).
   * **Histograms & KDE:** Passenger age distribution and density.
   * **Pie Charts:** Gender proportion breakdown.
   * **Scatter & Line Plots:** Fare vs. Age distributions and trends across demographic groups.
2. **Interactive Power BI Dashboard:**
   * **KPI Header Cards:** Overall passenger count and average survival rate.
   * **Demographic & Class Breakdowns:** Stacked column and 100% stacked bar charts showing survival rates by gender and class.
   * **Interactive Slicers:** Dynamic filtering by embarkation port (`Embarked`) and passenger class.
